# 🚗 Sistema de Estacionamento

> "Gerenciamento de veículos de forma prática e rápida pelo terminal."

## 📖 Sobre o Projeto

Este é um **Sistema de Estacionamento** interativo desenvolvido em **C#** (Console Application). O objetivo do sistema é gerenciar as vagas de um estacionamento, permitindo cadastrar veículos, listá-los e calcular o valor final a ser cobrado na saída do cliente com base no tempo de permanência.

## 🚀 Tecnologias Utilizadas

| Tech | Função |
|---|---|
| **C#** | Linguagem principal para a lógica do sistema. |
| **.NET** | Plataforma de desenvolvimento. |

## ⚙️ Funcionalidades

- **Adicionar veículo:** O usuário insere a placa do veículo, que é salva na memória.
- **Remover veículo:** Calcula o valor do estacionamento e remove a placa da lista.
  - Verificação de taxa fixa de entrada (R$ 5,00).
  - Cálculo de valor por hora de permanência (R$ 2,00/hora).
- **Listar veículos:** Exibe uma lista com as placas de todos os carros atualmente estacionados.

## 🔧 Como Rodar Localmente

1. Clone o repositório.
2. Abra o terminal na pasta do projeto.
3. Execute o comando `dotnet run`.
4. Escolha as opções no menu e divirta-se!
